# The Costillas Garden 🥩🔥

Landing page oficial de **The Costillas Garden**, restaurante de BBQ y ahumados artesanales especializado en Brisket Black Angus Prime y Costillas al estilo Central Texas ahumadas con leña seleccionada.

Instagram oficial: [@thecostillasgarden](https://www.instagram.com/thecostillasgarden/)

---

## 🛠️ Stack Tecnológico

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Estilos**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Iconografía**: [Lucide React](https://lucide.dev/) + SVGs personalizados
- **Animaciones & Efectos**: [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Tipografía**: Google Fonts ([Montserrat](https://fonts.google.com/specimen/Montserrat), [Cinzel](https://fonts.google.com/specimen/Cinzel), [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans))

---

## ✨ Características

- 🥩 **Hero Section de Alto Impacto**: Logotipo en plata cepillada/cromo, badges de humo activo y métricas clave del pit.
- 🪵 **Técnica de Ahumado Artesanal**: Detalle de maderas nobles (roble blanco, manzano, mezquite) y los 4 pasos del ahumado a 225°F.
- 📜 **Menú Dinámico y Filtrable**: Renderizado desde estructura de datos, con buscador en tiempo real, especificaciones técnicas de corte y badges de insignia.
- 📅 **Modal de Reservación Interactivo**: Selector de fecha, hora, número de personas y zona del restaurante con confirmación inmediata y enlace directo a WhatsApp.
- 🛍️ **Mi Selección BBQ (Order Drawer)**: Carrito lateral con ajuste de cantidades, desglose de subtotal/impuestos y envío de pedido estructurado a WhatsApp.
- 📍 **Horarios & Contacto en Vivo**: Horarios semanales, enlaces a Google Maps, llamada rápida y membresía VIP *"La Logia del Humo"*.
- 📱 **100% Responsivo**: Adaptado para smartphones, tablets y pantallas de escritorio.

## 🚀 Inicio Rápido

### Prerrequisitos
- [Node.js](https://nodejs.org/) (versión 18 o superior)
- npm

### Instalación
```bash
# Clonar el repositorio
git clone https://github.com/yadoble/thecostillasgarden.git

# Entrar a la carpeta
cd thecostillasgarden

# Instalar dependencias
npm install
```

### Ejecutar en Desarrollo
```bash
npm run dev
```
Abre [http://localhost:5173](http://localhost:5173) en tu navegador.

### Compilar para Producción
```bash
npm run build
```
Los archivos optimizados para producción se generarán en la carpeta `/dist`.
